# Матанализ: подготовка к экзамену за 30 дней

Веб-приложение для подготовки к устному экзамену «Математический анализ», I семестр (2026/2027).
Теория — в формулировках, близких к учебникам Д. Т. Письменного и А. А. Гусака.

**Открыть:** https://alt-7-dev.github.io/matan-exam-prep/

## Что внутри

- **59 билетов** в устном формате: план ответа, что говорить, доказательство, дополнительные вопросы.
- **204 вопроса с автопроверкой**: тест по каждому билету разбит на части, после каждого ответа — развёрнутый разбор.
- **План на 30 дней**: новые билеты, дни повторения, пробный экзамен.
- **Интервальное повторение**: результат теста задаёт оценку билета и дату следующего повторения (1–7 дней).
- **Прогресс**: карта билетов, полоски по разделам, календарь, серия дней.

Прогресс хранится в браузере (localStorage), регистрация не нужна.

## Структура

```
index.html        готовый сайт (одним файлом, без зависимостей)
src/shell.html    разметка, стили и логика приложения
src/content.js    теория по билетам и план на 30 дней
src/quiz.js       вопросы тестов
src/explain.js    развёрнутые разборы к вопросам
build.py          собирает index.html из src/
```

После правок в `src/` запустите `python3 build.py`.

> Теория составлена по памяти о формулировках учебников; перед экзаменом сверяйте с конспектом лекций.
